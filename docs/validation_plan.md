# 工程验证计划（阈值待确认）

本计划用于形成原型验证证据，不代表已有测试结果。运行压力、设计压力、压差、压力循环范围、泄压设定、允许泄漏率、电流和温度限值均为 **TBD**。这些阈值必须由系统危险评估、材料供应商数据和结构计算确定；本文件不设定压力额定值或扭矩。

## 1. 输入与设计审查

- 冻结待测配置：电极数（3/5/7）、间隙（2/4/6 mm）、电解液完整组成、温度、流量、泵/歧管方案、材料与表面处理。
- 明确正常工作压差、最大可信堵塞/故障压力、泄压/停机值、允许泄漏判据、允许温升和绝缘要求；记录依据及批准人。
- 核实密封圈供应件的截面公差、材料、压缩率建议、介质/温度兼容性、压缩永久变形数据；核实框、板、软管、接头和粘接/连接材料。
- 完成端板弯曲/挠度、杆件及螺母/垫圈、框体局部应力、密封压紧力/均匀性、热膨胀和薄电极差压挠曲计算。若压力下外侧阴极需背衬，应先纳入设计。

## 2. 文件与零件级检查

- 使用 OpenSCAD 对 `electrode_count=3,5,7` 及间隙配置进行预览/渲染；确认总高尺寸链、板面朝向、流道数、电极耳干湿区和孔位。
- 分别检查框、自由密封件、电极、端板、绝缘板、杆件和流体接口的可拆分性；核对 STL/DXF 等网格/平面输出，不把渲染通过当作结构证明。
- 查看每个框两面的局部剖面：闭合槽无中断，入口/出口孔贯通活动窗且不切断密封路径；检查孔至槽、孔至框边及孔之间的最小实体厚度。
- 依据正式制造图测量框厚、槽宽/深、槽中心线、平面度、平行度、电极厚度/翘曲、端板厚度、孔径和位置；记录测量设备、结果和不确定度。
- 逐层干装。确认密封圈未扭曲、拉伸、挤出或跨越孔口；确认框体硬止挡接触、电极窗口无遮挡、耳片/母线/端板/绝缘/拉杆互不干涉且异极无短路路径。
- 现无已定型的电极横向定位特征；在装配验收前设计并验证定位夹具/治具，确认重复堆叠位置和密封压合区域一致。
- 在微管—框体的密封与机械保持/防脱设计完成、接口加工公差确定并通过独立压力验证前，不得把流道框视为可用于实际带液服务的可制造件。

## 3. 夹紧与密封接触检查

- 在受控夹具中按经过计算批准的紧固顺序和预紧方法装配，记录紧固件、润滑/表面状态、加载顺序和测得的夹紧力或经校准方法。不得凭本文件推导扭矩。
- 用压敏膜、间隙测量、端板位移或等效方法检查周向接触与载荷均匀性，尤其是角部、耳片附近、杆间中点及端口附近。OpenSCAD 无法证明压紧均匀。
- 检查硬止挡是否真正接触，端板挠曲是否导致局部过压/欠压；记录拆装前后压缩痕迹和密封圈损伤。出现局部缺接触或止挡未到位，停止后续压力试验并修正设计/装配。

## 4. 冷态液体检漏与压差

- 仅在确认测试介质与材料兼容、设定压力阈值已批准、系统已安装压力监测和安全泄压后开始。使用适当的低风险液体测试介质；不得将产气反应液用于首轮密封验证。
- 分通道检查入口—活动窗—出口的贯通、堵塞、串流和排气能力；逐条隔离测试，排除外部管线接头漏点后再判定堆叠体。
- 采用经批准的阶梯压力/压差程序，每级稳定后记录入口/出口压力、温度、保压时间、压力衰减、外表面渗液、通道间串漏和端板位移。所有压力级和保压时间待批准，不得现场自行上调。
- 按系统泵曲线和堵塞情形验证运行压差与泄压/停机动作；不得把泵的最大能力直接施加于未经额定的堆叠体。
- 判据：无可见外漏或通道串漏；压力保持/衰减符合预先批准的量化限值；端板和框体无永久变形；电气干区保持干燥。具体检漏灵敏度、允许衰减和“通过”阈值需事先定义。

## 5. 热态与循环验证

- 冷态通过后才评估热态。采用已确认兼容的测试介质，在受控温度下逐步升至实际批准工况（60–85 °C 范围内具体值 TBD），记录温度梯度、压力、预紧保持、外漏、串漏和板/端板位移。
- 进行热浸、冷热循环、压力循环和启停循环，循环次数、升降温速率、压力幅值和停留时间由寿命目标及危险评估确定。不得把循环测试替代材料相容性试验。
- 运行后拆解检查圈的裂纹、鼓胀、溶胀、压缩永久变形、挤出/切伤，槽和端面腐蚀/沉积、框体蠕变、紧固件松弛、电极翘曲、孔道隔壁损伤和铜连接腐蚀。重新装配后重复必要的低压检漏。

## 6. 电气与过程验证

- 在干态/安全隔离条件下检查阳极彼此导通、阴极彼此导通、异极间绝缘、各耳片与框/拉杆/端板绝缘，以及铜件只位于干区。测量母线连接电阻、各支路电流与温升。
- 首次电化学运行须在单独批准的风险评估与系统安全设施下执行。验证支路流量分配、气液分离、持续排气、压力监测与联锁、温度、电流、电压和产气去向；设置安全停机判据。
- 无隔膜体系需分析产品交叉、气体混合与可燃性风险。未有经审查的安全排放与监测方案前，不进行产气运行。

## 7. 记录与验收交付

保存图纸/参数版本、BOM 批次、材料证明、密封圈供应商资料、装配记录、测试介质、仪器校准、原始压力/温度/流量/电流数据、照片、异常与整改记录。只有全部预先批准的结构、密封、热态、循环、电气及系统安全验收项通过，且剩余问题有书面处置后，才能评估下一阶段试验或制造放行。
