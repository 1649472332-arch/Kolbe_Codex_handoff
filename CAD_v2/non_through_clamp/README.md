# 非贯穿螺栓压滤式 Kolbe 电解池外壳（CAD_v2）

路径：`CAD_v2/non_through_clamp/`

机械概念模型（OpenSCAD）。**压力 / 密封 / 化学相容性均未验证。**

## 设计意图

在协作方 version2（约 73.7×81.7、端板 20 mm、薄框 4 mm、6×M6 **通杆贯穿**全部模块）的外形尺度上，改为：

1. **夹紧只发生在两块厚端板之间**：短 M6 从外侧拧入后板；
2. **中间所有流道框 / 电极框没有螺栓孔**，螺栓轴从框外轮廓旁的空隙穿过；
3. **叠装对位靠周向舌槽（定位凸台/槽）**，销钉仅作辅助。

## 与贯穿螺栓版的区别

| 项目 | version2 / `kolbe_stack.scad` / CAD_v2 B1 | 本目录 non-through |
|------|------------------------------------------|-------------------|
| 中间框螺栓孔 | 有（通杆贯穿） | **无** |
| 端板 | 与框同宽或通孔 | 放大至约 96×106，螺栓落在框外 |
| 后板紧固 | 通杆+螺母 | 默认 **热熔铜螺母沉孔 Ø8×8**（可选攻丝钻底孔 Ø5×13） |
| 对位 | 依赖螺栓孔同心 | **每层舌槽嵌合** + 可选 Ø3 销 |
| 供液 | 侧孔或面口 | 前端板双凸台 + Ø6 通孔（卡套观感，无真实螺纹） |

## 关键尺寸（默认值）

| 参数 | 数值 mm |
|------|---------|
| 流道框外廓 | 74 × 82 × 4 |
| 端板外廓 | 96 × 106 × 20 |
| 工作窗 | 43 × 63 |
| 电极 | 28 × 28 × 1（带耳伸出顶部干区） |
| 夹紧 | 6×M6；前板通孔 Ø6.6；后板热熔螺母 Ø8×8 |
| 螺栓中心（相对中心） | (±42, ±47) 四角 + (±42, 0) 两侧 |
| 定位销（辅助） | Ø3，中心 (±28, ±35) |
| 舌槽 | 凸台 3.8×11×0.9；凹槽 4.2×11.4×1.05；中心距外缘 inset 4 |

默认装配层数：`frame_count=3`，`electrode_count=3`（框贴合活性段 12 mm，含端板总厚约 52 mm；电极居中于各框窗口腔内，不撑开周边舌槽）。

## 定位槽 / 凸台配合关系（必验）

采用**单向极化舌槽**，保证无螺栓孔时仍能周向 + 平面内对位：

```
前板内侧 ──(凸台 tongue)──► 第1框底面凹槽 groove
第1框顶面 tongue ──────────► 第2框底面 groove
第2框顶面 tongue ──────────► 第3框底面 groove
…
最后一框顶面 tongue ───────► 后板内侧 groove
```

- 每块**流道框**：−Z 面 4 处凹槽（±X / ±Y 边中点），+Z 面 4 处凸台（同 XY）。
- **前端板内侧面**：4 处凸台，嵌入第一块框的底槽。
- **后端板内侧面**：4 处凹槽，承接最后一块框的顶凸台。
- 凸台略小于凹槽（约 0.2–0.4 mm 间隙），FDM 友好；避免薄尖角（矩形 + 小圆角）。
- 电极只在窗口区内，不干涉周边舌槽。
- 另保留 2×Ø3 销孔作辅助；可调 `show_locator_pins`。
- 电极位于窗口腔内、不参与周边贴合厚度，因此框与框 / 框与端板的舌槽可以直接嵌合。

参数均在 `kolbe_non_through.scad` 顶部：`nest_*`。

## 装配顺序

1. 后板朝上放好，确认内侧凹槽朝向堆叠侧；热熔螺母已装入外侧沉孔。
2. 将流道框按「凹槽朝后板 / 凸台朝前」叠入，凸台落入后板凹槽。
3. 在窗口内放入电极（带耳朝上干区，耳片错开）。
4. 重复框 + 电极至设计层数。
5. 盖上前端板：前板内侧凸台落入第一框凹槽；两只接头凸台朝外。
6. 可选：插入 Ø3 定位销。
7. 6×M6 短螺栓 + 垫圈从**前板外侧**穿入，拧入后板热熔螺母；**不要**穿过中间模块实体。
8. 手紧后均匀对角加力；密封与压力需实验标定（未验证）。

## 打印 / 攻丝说明

- **材料建议**：框与端板 PETG / ABS / 尼龙；电极为金属另制，打印件仅作外形示意。
- **后板紧固（推荐）**：`rear_fastener_mode = "heatset"`，沉孔 Ø8×深 8，压入 **M6 热熔铜螺母**。3D 打印塑料牙不适合夹紧载荷。
- **可选机加工后板**：`rear_fastener_mode = "tap"`，钻底孔 Ø5.0×深 13，攻 M6×1.0（POM/PEEK/金属）。
- 舌槽与密封槽朝上打印可减少支撑；端板厚件注意填充与热变形。
- 前板接头孔为 Ø6 通孔 + 沉台概念，**不是**真实 G1/8 螺纹。

## 未验证项

- 工作压力、密封压缩量、泄漏率
- 电解液 / 产物对打印材料与热熔螺母的化学相容
- 夹紧载荷下端板弯曲、框窗变形
- 电极并联汇流与绝缘
- 热熔螺母拉拔强度与反复拆装寿命

## 如何预览

```bash
# GUI
openscad CAD_v2/non_through_clamp/kolbe_non_through.scad

# 切换零件（Customizer 或 -D）
openscad -D 'part="frame"' -o frame.stl kolbe_non_through.scad
# part = assembly | exploded | front_endplate | rear_endplate |
#        frame | electrode_tab | electrode_plain | locator_pin

# 一键导出
./scripts/export.sh

# 浏览器演示（用本地静态服务或直接打开）
xdg-open demo.html   # 或把该文件拖进浏览器
```

`plate_style` 可设 `"octagon"` 做参考照片式切角；默认 `"rect"`。
