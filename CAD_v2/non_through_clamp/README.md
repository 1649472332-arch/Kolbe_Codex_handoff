# 非贯穿夹紧 Kolbe 电解池 — CAD 与离线装配演示

本目录实现 `PLAN.md` 的 Scope A / B，单位 mm，板面 XY，前板向后板为 +Z。八根 M6 仅穿过两块端板，在中间框外经过；中间的框、密封片、电极没有螺栓孔。属于机械概念样机，压力、密封及电化学性能尚未验证。

默认入口：[demo_v2.html](demo_v2.html)。直接双击即可离线打开：three.js r170、真实 STL、manifest 与界面均内嵌，无需服务或网络。历史 `demo.html` 原样保留，其旧几何不代表本设计。

**中央电极片已去掉上下两条连接桥。28×28×1 mm 中央片目前独立悬浮，与外圈及顶部电极引片不连通；当前模型没有支承/固定中央片的结构，不能直接当作可制造的一体电极。请用户/后续设计补充支承、固定及电连接方案。演示中的位置仅为设计位置，不代表固定问题已解决。** 外圈承载边、顶部引片、每片垫片、8 螺栓、止口和销孔均保持原几何。

## 止口、两销及密封定位

- 两侧唇中心 X=±34.75，长 60、宽 2；上下唇中心 Y=±38.75，长 54、宽 2。顶部通道 X=-18.3…-9.7 / 9.7…18.3，从 Y=36.5 向外贯穿肩和唇，底边无通道。
- 母槽由未倒角公止口轮廓向外偏置 **每侧 0.25**；包含端头、圆角、通道边。公唇顶最后 0.3 高度内收，槽口 0.3×45° 扩口。工作槽底外壁最小 1.0，扩口局部最小 0.7；肩内壁到电极/垫片外缘每侧 0.25。
- P1=(-29,20)，P2=(29,-17)，钢销 Ø4。前板内侧两个 Ø3.96×6 盲孔压入；装配销 Z=14…44，贯穿全部中间层并进入后板 4.8。后板盲孔深 6，端部余隙 1.2。
- 其余塑料件 P1 为 Ø4.4 圆孔；P2 为宽 4.4、总长 5.0 长圆孔，长轴沿两销连线 (58,-37)。非对称位置、圆/槽角色及单向公母止口共同防错；Z/X/Y 各 180° 的错误装配分别作实体碰撞检测。
- 平垫片 P1 Ø4.6；P2 宽 4.6、总长 5.2。两耳位置均有顶部 0.5 深的干区浅缺口；不切断内侧闭合密封线。所有 G 使用同一自由厚 0.8 STL，装配 Z 缩放 0.75 后真实厚 0.6。
- 电极两孔均 Ø6.6，钢销到金属孔壁径向净空 **1.3**；考虑外缘定位允许偏移 0.25 后至少 **1.05**。只有电极外圈由肩内廓定位，销孔只作非接触避让；这些结构不支承或固定中央片。钢销位于密封线外干区；潮湿、污染和爬电造成的电极间短路仍需实测。
- 电极承载边 66×74 R3，开窗 43×63 R3；居中 28×28 R1.5 片与外圈完全分离，无横梁或细颈。中央片上下各留空 17.5，左右各留空 7.5；原两桥中心 (0,±22.75) 的全厚区域为空。耳 Y=36.5…64.5，仅连外圈，接线孔 Ø3.2、Y=58.5；E1/E3 X=-14，E2 X=14，中央片位置未移动。

默认 `seal_mode="flat_gasket"` 无任何 O-ring 槽。`gasket_material="FKM"` 同几何。PTFE 默认设计压缩率 10%，压缩厚 0.72、前肩 0.72、框肩 2.44、总厚 60.04；必须重新导出几何，不能只换白色宣称等效。所有压缩率是待实验标定的设计点。

`seal_mode="oring"` 使用真正独立闭合密封圈：中心线路径 48×68 R5.5，自由截面 Ø1.2，压缩后面积守恒椭圆高 0.9、径向宽 1.6；自由 bbox 49.2×69.2×1.2，压缩 bbox 49.6×69.6×0.9。每个框两面各一条宽 1.8、深 0.3 槽，后板内侧一条，前板及电极无槽。G1/G3/G5/G7 槽在上侧刚性件，G2/G4/G6 在下侧刚性件。压缩圈有 0.3 进入槽，仍跨越 0.6 间隙；刚性 Z 链与默认相同。自由有效间隙 0.9，总厚 61.3。自由/压缩网格保持对应拓扑和中心线路径，不能全局缩放 XY。O-ring 无销孔，由槽定位；不支持 PTFE+O-ring。完整独立模式文件在 `stls/oring/`，不与默认实体混用。

## 八点夹紧与装配

| 螺栓 | XY | 对角拧紧序号 |
|---|---|---:|
| B1 | (46,50) | 1 |
| B2 | (0,50) | 5 |
| B3 | (-46,50) | 3 |
| B4 | (-46,0) | 7 |
| B5 | (-46,-50) | 2 |
| B6 | (0,-50) | 6 |
| B7 | (46,-50) | 4 |
| B8 | (46,0) | 8 |

前板八孔 Ø6.6；平面直接承托独立平垫圈，无头部/垫圈沉槽。后板 Ø6.6 从内面通到局部 Z=12，连通外侧 Ø8×8 热熔孔（全局 51.2…59.2）。只支持 `rear_fastener_mode="heatset"`，删除 tap 分支。铜套 Ø6.2 光孔不代表 M6 螺纹加工尺寸；真实滚花、导入和底孔由采购图纸及安装试样确定。

自动选择标准系列中满足有效啮合≥6、后侧露出≤3.5 的最短头下长度，默认 **M6×60**。头下平面 Z=-1.6，杆尖 58.4；在铜套内有效啮合 7.2，距后端 0.8，默认不露出。自由接触时初始啮合 5.8，可先起牙。螺纹仅作光滑包络，不模拟真实牙型。实际螺钉/螺母仍须按供应商图纸复核。

保守 XY 净距：中点垫圈到框 3；角点到框矩形包络约 6.73；头到框中点 4；杆到框中点 6；上中垫圈到耳边 4；到接口凸台最小 10；垫圈到端板直边 4，孔到板边 6.7。垫圈/头的投影也参与检查。

以下仅为外圈和夹紧堆叠的概念层序；独立中央片没有固定结构，实际装配前必须补充支承方案。

1. 前板内侧朝上，压入两钢销，先放 G1。
2. 依次放框、G、电极、G，确认母槽朝前板，电极耳左/右/左。
3. 盖后板；前侧各放平垫圈、插螺栓，确保八根都能正常起牙。
4. 核对肩面接触、止口未顶底，再逐级对角拧紧。

每轮固定 **B1→B5→B3→B7→B2→B6→B4→B8**。低载荷装配试验起点：手指起紧 → 0.15 N·m（30%）→ 0.30 N·m（60%）→ 0.50 N·m（100%），最后同序复核一轮。**这是未验证的打印塑料试验值，不是压力等级、额定扭矩或密封保证；限位肩应先按尺寸验收，不能靠加大扭矩修复尺寸误差。** 热熔孔、塑料蠕变及端板挠曲都可能使实际压缩偏离 CAD。

前板同一实体上有两个外伸 8 的接口凸台，(0,±27) 的 Ø6 孔贯通凸台及前板到工作窗；Ø10.5×3 沉台位于 Z=-8…-5。无真实管螺纹，不标 G1/8。流体在中央片周边连通，框没有新增 manifold 小孔；该概念不声称形成三个串联独立液室。

## 打印与未验证项目

先打印销孔及止口尺寸试样，校准 Ø3.96 过盈与滑配间隙。前板两面都有特征，单纯“槽朝上”不能保证无支撑；凸台、母槽、肩顶与密封面应选择支撑/桥接并去毛刺。密封面平整度试验目标 ≤0.05。层高 0.15–0.20、外壁至少 4 道，承压肩及铜套附近局部实心，均为打样起点，不构成承压资格。

金属电极、钢销、M6 螺钉、垫圈、铜套和密封件应另制或采购；不列为塑料打印件。尚需物理验证：夹紧载荷与端板/框变形、垫片实际压缩和回弹、密封压力/泄漏、化学相容性、电绝缘/湿干区污染爬电、热熔件拉拔、蠕变、循环寿命、接口标准及真实螺纹。

## 导出和审计

```bash
python3 -m pip install --break-system-packages -r scripts/requirements-cad.txt
./scripts/export.sh
python3 scripts/verify_cad.py --manifest stack_manifest.json --report /tmp/cad-audit.json
openscad -D 'part="frame"' -o /tmp/frame.stl kolbe_non_through.scad
```

`part` 支持 assembly、exploded、front_endplate、rear_endplate、frame、gasket、gasket_oring、gasket_oring_compressed、electrode_tab、electrode_plain、locator_pin、bolt、washer、heatset_nut、bolt_with_washer、manifest。`electrode_tab_right.stl` 用 electrode_tab 加 `tab_offset_mm=14` 导出。组合 bolt_with_washer 只用于查看，不作为单实体检查对象。

`stack_manifest.json` 来自 SCAD `instance_records()` 的 KOLBE_V1 echo，包含全部解析参数、派生尺寸、自由/压缩尺寸、稳定 id、局部/装配/爆炸 bbox、分组、变换、STL/源码 SHA256 和工具版本；文件记录包含实测体积与连通分量数，`electrode_design` 明示零桥、每电极两个实体、中央片无支承且不与引片导通。Python 不维护另一套装配坐标。中央件爆炸按真实自由 bbox 留净距 14；两销在前板之后，螺栓向前、螺母向后，五金不伸长。

导出在工作区暂存目录 `.cad-export-stage/` 完成，CGAL 网格与八张 PNG 全部成功、默认及 N=1/4/6、FKM、PTFE、O-ring 回归通过后才替换指定输出；保留用户额外文件。暂存目录可跨重启保存；失败后再次运行同一命令，会按源码、参数、依赖版本及产物 hash 复用已完成导出、检查和图片。成功发布后清理暂存及参数变体。无静默 preview fallback。每个 CGAL 三角形均保留，以标准 float32 binary STL 输出，循环调整顶点起点并排序三角形，消除遍历顺序差异；不焊接、删面或简化。重导一次默认几何及 manifest 比对 hash，断言错误输入必须失败。总装 PNG 的临时接触并集可能产生 non-manifold 接触警告，单独打印并记录到报告；该警告不豁免任何单件 STL 或干涉检查。其他警告及所有错误仍导致失败。

`renders/cad_verification.json` 保存默认、变体、错误输入及复现检查；`stls/oring/cad_verification.json` 保存 O-ring 完整检查。检查覆盖：有限坐标、正体积、面/边/水密及连通分量数（电极恰好两个，其余单件一个），全部实例及尺寸链，全对全 manifold 布尔干涉，限定前板两压入孔区域的唯一过盈，真实截面孔槽间隙、肩接触及移入 0.05 的碰撞、七处压缩、紧固通道与净距、销贯穿及金属避让、三轴翻转防错、闭合密封线、端口连通、电极中央片独立且形状不变、全窗口间隙无桥、两条旧桥区域全厚为空及引片仍与外圈相连。容差：长度/bbox 0.02，布尔接触碎片 0.01 mm³。CAD 检查不等于上述物理验证。

正式渲染：`renders/assembly.png`、`exploded.png`、`frame_front.png`、`frame_rear.png`、`gasket.png` 均 1600×1200；两个新几何预览 1200×900；另有正视电极 `renders/electrode_isolated.png`（1600×1200）。离线演示及浏览器截图的构建命令见下节。

去桥版本检查：默认 574/574；N=1/4/6 分别 387/660/842 项；FKM 574 项、PTFE 569 项、O-ring 528 项，均通过。完整结果见 `renders/cad_verification.json`；导出需全部通过才发布。每个电极 STL 为两个正体积、水密实体，其余单件为一个；不把中央片悬浮视为支承验证通过。接触总装临时并集的 PNG 警告保留在报告中。

`renders/electrode_bridge_removal.json` 另存 11 项修改前后比对：8 个非电极 STL 哈希完全不变；三种电极仅移除原上下两桥、每种移除 140 mm³，新增体积及移除形状差均为 0。
